# sites

Static sites published from the Multicast hub with `hub-site publish`, served at `https://sites.aimulticast.org/<user>/<site>/`.

The hub service `hub-sites` writes here through the `multicast-hub-sites` GitHub App and checks every site for secrets before it is committed. Do not edit user folders by hand; remove a site with `hub-site unpublish` or ask a hub admin.
