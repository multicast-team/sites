Формулы и ограничения данных

Каждая таблица независимо фильтрует события по версии, платформе, стране, периоду наблюдений и дате установки. Один игрок может входить в обе версии после обновления. Пустые даты установки включают игроков с неизвестной датой; любой фильтр установки исключает их. Цвета рассчитываются внутри каждого столбца каждой таблицы.

Win rate = события победы / старты. Fail rate = показы Out of Moves / старты; продолжения могут дать несколько показов за попытку. Complete rate = прошедшие / начавшие игроки. Conversion = доля прошедших, начавших следующий уровень после победы. Tries и Time total зависят от выбранной группы игроков. Наведите на заголовок или ячейку времени для подробностей.

Время восстанавливается по событиям, включает фон, паузы и рекламу. Неизвестное время и неотслеживаемые ошибки показаны как «—». Первая победа означает первую наблюдаемую за выбранный период. Маленькие выборки нестабильны. Снимок Reporting API предварительный: порядок событий в одну секунду неизвестен.

Выгрузка из AppMetrica

Для обновления нужен API-модуль на этом компьютере. Облачный модуль недоступен по адресу 127.0.0.1 — этот адрес всегда указывает на компьютер, где открыт браузер. Скачайте файл запуска для Mac, распакуйте архив и дважды нажмите «Запустить Bubble Sort.command». Если модуль уже запущен, выберите период и нажмите «Обновить выбранный период».
