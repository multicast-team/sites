Claude для Windows не запускается: порядок проверки

Диагностика приложения, восстановление и проверка сети.

1. Уточните симптом

Приложение не появляется, закрывается сразу или показывает сетевую ошибку? Проверьте, запускается ли веб-версия, и посмотрите официальный статус. Ошибки сети и повреждённая установка требуют разных действий.

2. Завершите и восстановите приложение

Откройте параметры Windows → Приложения → Установленные приложения → Claude → Дополнительные параметры, если этот пункт доступен для вашей установки. Завершите приложение и выберите восстановление. Не путайте восстановление со сбросом данных.

3. Если Windows сообщает, что приложение работает

Закройте окно Claude и проверьте оставшиеся процессы приложения в диспетчере задач. Завершайте только процессы Claude, затем повторите восстановление. При необходимости перезагрузите Windows.

4. Проверьте результат

Запустите приложение снова и проверьте вход и обычный запрос. Если потребуется переустановка, заранее сохраните важные данные и используйте официальный установщик.

Почему помогает восстановление

Обновление может не завершить замену файлов, если старый процесс остался активен. Восстановление проверяет установку. Оно не исправляет ограничения аккаунта, недоступность сервиса или неправильный маршрут прокси.

Если проблема осталась

Сохраните текст ошибки, версию приложения и Windows. Сравните IP приложения и браузера, настройки DNS, системное время и сертификаты. Передайте эти сведения в официальную поддержку без токенов и паролей.
