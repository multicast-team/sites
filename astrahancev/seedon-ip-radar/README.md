# Seedon IP Radar

Статический сайт проверки IP и сетевого окружения от Seedon (ООО «Сидон»). Все ресурсы работают под произвольным префиксом пути.

Для установки на seedon.ru/ip/ скопируйте содержимое `.publish/` в соответствующую папку веб-сервера. Сборка не требует Node.js на сервере. Правило `seedon.ru → DIRECT` на устройстве определяет маршрут плашки прямого IP.

Проверки из папки сайта:

```sh
python3 tools/verify.py
node tools/verify.mjs
```

API геолокации и рисков остаются внешними: ip.net.coffee; гео-фоллбэк — ipwho.is. Статусы — официальные Statuspage. Для Turnstile на своём домене нужны свои ключи и endpoint верификации; исходные доменные ограничения показаны в интерфейсе.

Подробности, список файлов и ограничения: [REPORT.md](REPORT.md).
