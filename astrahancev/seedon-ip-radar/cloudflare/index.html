Cloudflare Что показывает проверка узлов

Многие сайты используют Cloudflare. При обращении к такому сайту, запрос сначала поступает на пограничный узел, перед обращением к исходному серверу Cloudflare БлижайшийПограничный узел (Дата-центр, Cloudflare обозначается как colo), Узел обращается к исходному серверу сайта. Выбор узла, влияет на скорость открытия, стабильность видео, и определение региона пользователя. Страница обращается к Cloudflare для cdn-cgi/trace API с запросом, Полученный код узла, Выходной IP, WARP Статус, и версию протокола показывает в понятном виде.

Cloudflare Параметры соединения. Чем ниже значение, тем лучше; 60 и выше может означать Cloudflare повышенную вероятность капчи или ограничений.   • Автоматически пройдена: Turnstile Проверка завершилась без действий пользователя, это означает Cloudflare Браузер и сеть выглядят надёжно, Это ожидаемый результат.
  • Нажмите для проверки: Управляемый режим показал«Подтвердите, что вы человек»поле подтверждения, Нажмите для подтверждения. Окружение в целом нормально, есть отдельные подозрительные признаки.

Частые вопросы

Что такое Cloudflare Пограничный узел (colo)?

Cloudflare По всему миру 135 стран и регионов, развёрнуто 342 дата-центров, Дата-центры обозначаются трёхбуквенными кодами (например HKG Гонконг, NRT Токио, SIN Сингапур, LAX Лос-Анджелес). При обращении к сайту с Cloudflare подключением к этой сети, запрос поступает на выбранный пограничный узел, а затем на исходный сервер. Страница читает Cloudflare для cdn-cgi/trace API, и показывает город и страну выбранного узла.

Почему бесплатный и корпоративный тарифы используют Cloudflare разные узлы?

Cloudflare Для разных тарифов могут действовать разные сетевые политики. Бесплатный тариф и Pro трафик соответствующего тарифа в части регионов (в частности из Китая, и части сетей Юго-Восточной Азии)могут направляться на более удалённые узлы, Например, на западное побережье США LAX, SJC; Корпоративный тариф и Cloudflare собственные сервисы (1.1.1.1, cloudflare.com, speed.cloudflare.com)могут использовать HKG, NRT, SIN ближайшие узлы. Таблица сопоставляет узлы и задержку разных тарифов на одном маршруте, Различия видны в сравнении.

Cloudflare Выходной IP и обычный выходной IP IP В чём разница?

Обычный выходной IP IP адрес, который видит сайт при соединении; Cloudflare Выходной IP адрес при обращении к Cloudflare подключением к этой сети, Cloudflare зафиксированный пограничным узлом. Если правила прокси направляют Cloudflare трафик отдельно, адреса могут различаться. Сравнение выходных IP на главной и этой странице IP помогает проверить правила.

WARP Что это?В результатах warp=on и warp=plus что означает?

WARP Да Cloudflare сервис зашифрованного туннеля, После включения трафик сначала поступает в Cloudflare сеть и затем выходит из неё. warp=off Не используется WARP; warp=on Используется бесплатная версия WARP; warp=plus обозначает WARP+ Платная версия. Включение WARP при, Выходной IP становится Cloudflare адресом сети (AS13335), Для таких адресов некоторые сайты IP используют более строгие проверки.

Как оценить задержку?

Для узла в том же городе или регионе, От браузера до Cloudflare пограничного узла задержка часто составляет 5 до 60 мс; До западного побережья США примерно 120 до 200 мс; более 300 мс может указывать на длинный маршрут или удалённый узел. Показано время фактического запроса браузера, Оно может быть выше сетевого RTT, Подходит для сравнительного анализа тарифов.

HTTP/3 и TLS 1.3 Что делать, если протокол не включён?

HTTP/3 На основе QUIC (UDP 443), Браузер может переключиться при повторном запросе к сайту на HTTP/3; Если постоянно показан HTTP/2, проверьте ограничения прокси и межсетевого экрана UDP 443. TLS 1.3 Современный стандарт, Современные браузеры поддерживают по умолчанию, Отображается TLS 1.2 Возможно, промежуточный прокси выполняет TLS понижение версии или анализ трафика.

Turnstile Чем автоматическая проверка отличается от подтверждения?

Turnstile Да Cloudflare Проверка браузера. Автоматический режим работает в фоне; В управляемом режиме Cloudflare учитывается отпечаток браузера, репутация сети и поведение при выборе способа проверки. Автоматическое прохождение означает Cloudflare высокое доверие к окружению; Подтверждение может требоваться при отдельных подозрительных признаках; Ошибка после подтверждения требует дополнительной диагностики, При обращении к Cloudflare сайту возможны повторные проверки и ограничения. На этой странице token токен передаётся API проверки для подтверждения результата, Отображается PASS Только подтверждённый результат считается завершённой проверкой.

Сохраняется ли мой IP ??

Нет. Проверки отправляются непосредственно из браузера к Cloudflare соответствующим API, История узлов хранится только в браузере, Сетевые проверки используют сторонние API.
