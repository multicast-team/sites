# Seedon IP Radar — адаптация 2026-11-06

Источник задачи: прямое поручение Максима в T3, 06.11.2026. Все правки ограничены этой папкой.

Обнаружено при первичной проверке:
- Навигация, стили, скрипты и динамические IP-ссылки привязаны к корню домена. Для статического хостинга нужны относительные пути и параметр `?ip=` вместо серверного маршрута `/ip/{address}`.
- В клоне отсутствуют растровые favicon, флаги, Open Graph изображения и `ip/land110.txt`; корневые ссылки на них дают 404.
- Статусы используют отсутствующие локальные JSON и устаревший встроенный снимок; требуется официальный источник и честное состояние «нет данных» при сбое.
- Запросы DIRECT направлены в китайские сервисы; заменить цепочкой Seedon → Яндекс → ipify, указав источник и ограничения фоллбэков.
- Есть Google Analytics и скрытая отправка IP-сессии третьей стороне. Счётчики и отправку сессий убрать при адаптации бренда.

Требования: русский интерфейс, Seedon (ООО «Сидон»), API ip.net.coffee по абсолютным URL, гео ipwho.is, официальные Statuspage Claude/OpenAI, работа под любым префиксом пути. Дизайн сохраняется.

QA: порт 8765 занят, используется отдельный свободный порт. При проверке найдена ошибка экранирования в новых шаблонных IP-ссылках; исправляется до браузерного прогона.

Расширенная статическая проверка обнаружила оставшиеся preconnect/dns-prefetch к Google Tag Manager в 8 страницах. Удалены вместе со счётчиком.

Проверка GET подтвердила: captcha/config возвращает 200 и CORS *, а land110.txt — 200 без CORS (59 887 байт). HEAD у этих маршрутов отвечает 403 и не отражает работу GET. Файл карты размещён локально, чтобы устранить CORS. В ответе lookup найдены дополнительные китайские термины Anycast; добавлены в словарь.

Браузер Cloudflare: виджеты Turnstile исходного сайта вернули код 110200 (домен не разрешён ключом). Вместо ложной оценки риска показано понятное сообщение о необходимости собственных ключей и серверной верификации. Это ограничение внешней конфигурации; тестовые ключи не подставлялись. Полный тест скорости не запускался из-за расхода трафика.

Финальная проверка РФ-адаптации: исходная DNS-эвристика искала только китайские резолверы. Заменена на обнаружение российских резолверов при иностранном выходе. Отсутствие результатов DNS теперь нейтрально и не объявляется доказательством безопасности.

Итоговый прогон: 17 HTML, 10 JS, 44 inline JS, 486 локальных ссылок, 0 ошибок; 13/13 сетевых проверок. Публичная выкладка отправлена в очередь. Временные скрипты перевода удалены, оставлены воспроизводимые проверки и результаты.

Финальное состояние: сборка и проверки готовы; публикация принята, но хостинг ещё разворачивает сайт (HTTP 404 на последней проверке). Временный сервер остановлен по PID, собственная браузерная вкладка закрыта.
