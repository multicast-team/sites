Что исправлено в этом HTML-прототипе (и переносится 1:1 в игру)

1. Прокачки: без мусора сверху + настоящий скролл Убран верхний блок с прогрессом Ямы и кривыми стрелками вниз. Убраны кнопки страниц < 1-4 | 5-7 > — теперь обычный вертикальный скролл.
2. Цифры апгрейдов: Серое → Зелёное Старое значение — серым (1,80с), стрелка и новое значение с приростом — ярким зелёным (→ 1,64с (-0,16с)).
3. Дерево уровней Ямы: в рамках экрана + стрелки ↑ Окно привязано к высоте экрана со скроллом внутри (не вылезает наверх/вниз). Все стрелки между уровнями смотрят строго вверх ↑.
4. Сборщик 1 + Мотор справа + Авто-кружок с таймером Кружок Мотора $470 стоит справа и не касается кружка сборщика. С мотором кружок сам заполняется по таймеру (1,8с), а когда встаёт игрок — включается быстрая ручная скорость (1,5с).
5. Конвейер: 3 покупки всё ближе к Яме Нажми кнопку «Лента: Шаг 0/3 → 1/3 → 2/3 → 3/3»: лента строится в 3 этапа всё ближе к Яме, а не с первого раза до конца.
6. Лифты удалены, Дом шпули у левой стены, Белый пол Лифты лутбоксов удалены навсегда (коробки спавнятся сами у табло сверху, ревард — между сборщиком и Ямой). Белый контрастный пол с полосками и правая кнопка «Прокачки» возвращены.

Как устроен UI в Unity сейчас и как переводим на UI Toolkit (UXML + USS)

Сейчас в проекте UI написан кодом на старом uGUI (RectTransform в C# без CSS-вёрстки), поэтому агенты ошибались с вылетами за экран и стрелками. В нашей версии Unity 6000.6.0f1 уже встроен модуль com.unity.modules.uielements (UI Toolkit) — это прямой аналог HTML (.uxml) и CSS Flexbox (.uss):

1. Одобренный тобой HTML / CSS
<div class="upg-card"> <div class="upg-info"> <span class="upg-name">Руки</span> <div class="upg-stat-diff"> <span class="stat-old">1,80с</span> <span class="stat-new">→ 1,64с (-0,16с)</span> </div> </div> <button class="upg-buy-btn">$190</button> </div>
2. Прямой перенос 1:1 в Unity UXML / USS
<ui:VisualElement class="upg-card"> <ui:VisualElement class="upg-info"> <ui:Label class="upg-name" text="Руки" /> <ui:VisualElement class="upg-stat-diff"> <ui:Label class="stat-old" text="1,80с" /> <ui:Label class="stat-new" text="→ 1,64с (-0,16с)" /> </ui:VisualElement> </ui:VisualElement> <ui:Button class="upg-buy-btn" text="$190" /> </ui:VisualElement>
